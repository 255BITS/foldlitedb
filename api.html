The Python API

Start with add, add_many, and rows. Explicit documents and cursors are available when your application owns a log or a resumable feed.

Database

Database(path, *, generation="default", reset=False,
         max_batch=1024, max_batch_bytes=8 * 1024 * 1024,
         max_value_bytes=1024 * 1024, max_key_bytes=4096,
         max_page_bytes=8 * 1024 * 1024,
         max_emissions_per_document=1024, timeout=30)

A local SQLite view cache, safe to share between Python threads. Separate instances and processes serialize writes through SQLite. Use a context manager or call close().

generation identifies the source collection. A conflicting generation requires an explicit reset=True, which discards derived storage and invalidates existing instances and cursors. Retain authoritative documents before resetting.

LimitMeaning
max_batchMaximum documents in one atomic ingestion call.
max_batch_bytesEncoded payload, document-ID, and source bytes per batch; also bounds pending map values.
max_value_bytesEncoded payload, contribution, reducer-state, and finalized-result size.
max_key_bytesEncoded canonical JSON key size; cannot exceed 4096.
max_page_bytesTotal key, state, and result bytes in a returned page.
max_emissions_per_documentBounds map output for each document.
timeoutSQLite lock wait in finite seconds, from 0 to 2147483.647.

Adding documents

add

db.add(payload, *, id=None, source="default", position=None) → Document

Append any finite JSON value. Omitted IDs are generated; omitted positions start at zero or follow the source checkpoint. The returned payload is a separate JSON value, isolated from caller and mapper mutations.

An identical named retry reuses its original position. A source and position can also identify an identical unnamed retry. Conflicting identity reuse raises DocumentConflict; a new document behind its source checkpoint raises SourceOrderError.

add_many

db.add_many(payloads, *, source="default") → tuple[Document, ...]

Eagerly consume one bounded iterable of JSON payloads and append it atomically. Every member is one payload, so an array is kept whole. Results preserve input order and have generated IDs and consecutive source positions. Empty input returns ().

Input errors, map failures, limits, and position exhaustion roll back the entire batch. Retrying this unnamed call adds another batch. Replay retained documents with ingest.

Explicit documents and batches

Document(id, payload, position, source="default")
db.ingest(documents) → IngestResult
db.ingest_many(documents, *, batch_size=None) → iterator[IngestResult]

ingest atomically commits a bounded batch of explicit Document records. Identical replay performs no map work and must match the ID, position, and payload. Its result has inserted, replayed, and the committed ingestion sequence.

ingest_many is lazy: iteration commits separate bounded batches. The default batch size is max_batch; a failure preserves previously committed batches.

Views and reducers

View(name, version, map, reducer, references={})
db.register(view) → revision

A map receives a Document and yields zero or more (key, contribution) pairs. Keys and values may be structured finite JSON. Each key owns a reducer state. The view version identifies map behavior; references declares captured external-input versions.

Register callbacks on every instance that reads their views. Registration reuses compatible persisted state or rebuilds a changed definition atomically. Query and change reads catch registered callbacks up after another connection ingests documents.

Numeric reducers

Mean(*, runtime=None, positioned=False)
Sum(*, runtime=None, positioned=False)
Count(*, runtime=None, positioned=False)
Envelope(*, runtime=None, positioned=False)
RustReducer(name, *, runtime=None, positioned=False)

The named constructors use the same descriptors and state formats as their explicit reducer IDs. They load the optional runtime when computation needs it. Ordinary maps emit finite numbers or null; null contributes nothing.

ConstructorReducer IDResult
Mean()mean/v1{"count": n, "value": mean}; empty value is null.
Sum()sum/v1Count and sum; empty sum is zero.
Count()count/v1Count and count value; counts non-null numeric emissions.
Envelope()envelope/v1Count and first/min/max/last points, each with value and position.

Map a document to 1 to count it. Envelope order uses source positions plus deterministic identity/emission tie breaking. positioned=True accepts explicitly positioned portable contributions; it is intended for adapters that already own that position schema.

OrderedFold

OrderedFold(initial, step, *, version, finalize=None)

A trusted Python fold for structured state. step(state, contribution) returns the next finite JSON state. Steps run in persisted ingestion order within a key. Ordered folds do not declare arbitrary partial-state merging.

from foldlitedb import Database, OrderedFold, View

def statuses(document):
    yield document.payload["record"], document.payload["status"]

status = View("status", "1", statuses,
              OrderedFold(None, lambda previous, value: value, version="1"))
with Database(":memory:") as db:
    db.register(status)
    db.add_many([
        {"record": "a", "status": "open"},
        {"record": "a", "status": "closed"},
    ])
    assert list(db.rows("status"))[0].result == "closed"

Rows, snapshots, and changes

rows

db.rows(name, *, key=<omitted>, limit=100) → iterator[Row]

Lazily iterate a stable snapshot in bounded pages. The first iteration selects its committed prefix. limit controls page size, from 1 to 4096; it does not cap total results. No transaction or lock spans a yield to application code.

Omit key for every group. Supplying any JSON key, including null, filters exactly. Keys follow canonical JSON lexical order. View rebuilds and compaction can expire a paused iterator.

query

db.query(name, *, key=<omitted>, limit=100, after=None, cursor=None) → Snapshot

A snapshot contains rows, cursor, after, and complete. Continue pages with both the original cursor and the returned after. Each Row contains key, finalized result, reducer state, and ingestion sequence.

changes

db.changes(name, *, since, limit=100) → ChangePage

Read committed key postimages after a snapshot or change cursor. A change page has rows, a continuation cursor, and complete. Continue using that page's cursor.

Changes coalesce repeated updates to the same key within one transaction. A page can split a transaction; its cursor retains per-key progress. Empty maps still advance progress.

Lookup and maintenance

get(identifier, *, source="default") → Document | None
Read a cached immutable document with a freshly decoded payload.
checkpoint(source="default") → int | None
Read the highest committed source position.
refresh(name)
Explicitly catch a registered view up to retained documents. Ordinary reads do this automatically.
compact(name, *, before)
Discard older change history while preserving the chosen snapshot boundary. The caller owns reader retention.
stats()
Return document, source, view, state, history counts and current ingestion sequence.

Errors

DatabaseError extends ValueError. Its specialized errors are DocumentConflict, SourceOrderError, CursorExpired, and GenerationMismatch. Failing callbacks propagate their exceptions and roll back their transaction. Missing numeric runtime support raises an actionable RuntimeError.
